# 刷题神器

一个适用于各学科的本地刷题工具：把自己的题目资料导入，校对答案后即可开始练习、积累错题和专注复习。

程序是单个 HTML 文件，优先支持 **Windows + Chrome / Edge**。无需安装软件、启动服务器或注册账号，文件解析和学习记录均在本机处理，断网也能使用。

**首次打开是空题库。** 程序不预装任何学科资料，也不会自动读取旧版刷题记录。

## 下载与开始使用

| 下载方式 | 适合谁 |
| --- | --- |
| [单文件版：刷题神器.html](./刷题神器.html) | 只需要程序，下载后双击使用 |
| [便携包：刷题神器_便携版.zip](./刷题神器_便携版.zip) | 需要程序、使用说明和 DOCX / TXT / Markdown 导入样例 |

在 GitHub 文件页使用 **Download raw file（下载原始文件）** 下载文件；不要把整个 GitHub 网页另存为程序。下载 ZIP 后先解压，再双击里面的 HTML。

1. 在 Windows 上双击 `刷题神器.html`；如果没有自动打开，可右键选择 Chrome 或 Edge。
2. 导入自己的 DOCX、TXT 或 Markdown 资料，预览识别出的题目、答案、解析和分类。检查待校对项，确认后保存。
3. 选择题库和分类开始练习。单选、多选、判断按标准答案判分；填空、简答和计算题可对照答案自评。

Word 首版只支持 `.docx`，旧版 `.doc` 请先转换。PDF、扫描件和 OCR 不在支持范围内。文件排版多种多样，复杂表格、公式或不明确的题号、答案可能需要手动检查；请以导入预览和原文为准。

## 主要功能

| 功能 | 说明 |
| --- | --- |
| 本地导入与校对 | 识别 DOCX、TXT、MD 中的题目、答案、解析和分类；支持字段编辑、跳过、合并及拆分 |
| 多题库管理 | 分别保存不同学科或资料的题目与练习进度 |
| 分类与检索 | 按知识点、题型、来源、关键词、未做、错题或收藏筛选，支持分页和随机顺序 |
| 判分与解析 | 单选、多选、判断自动判分；填空、简答、计算题对照答案自评 |
| 错题重刷 | 为错题创建新的练习轮次，保留历史记录和收藏 |
| 专注练习 | 1–180 分钟自定义倒计时，支持全屏、暂停和继续 |
| 完整备份 | 导出并恢复题库、图片、作答历史、草稿、收藏及计时快照 |

## 错题与专注练习

答错的题目进入当前错题本；再次答对后会移出当前错题本，过去的作答记录仍然保留。选择错题重刷会开始新一轮，并清空该轮的作答，不会删除以前的记录或收藏。

专注练习支持设置倒计时、暂停和全屏。时间到时会提醒并保留已保存的草稿，不会自动交卷。退出全屏不会自动暂停计时。

## 保存与备份

题库、图片和学习进度保存在当前浏览器的本地存储中，不在 HTML 文件里。请定期从数据管理中导出完整备份，并妥善保管备份文件；更换电脑或浏览器后，可通过导入备份恢复。移动 HTML、清理浏览器数据、使用无痕模式或切换浏览器时，原数据可能无法读取或被清除，单独复制 HTML 文件不会复制进度。

导入备份前请检查题库和冲突预览，再选择保留当前、采用备份或恢复为独立题库。通过备份恢复的未结束计时会暂停，用户确认后再继续。存储不可用或保存失败时，请按页面提示及时导出备份。

## 导入旧版题库

支持此前使用的、内嵌 `questionData` 数据的题库 HTML，读取其中的题目、答案、讲解与图片，不执行网页脚本。这个入口不是任意网页解析器。旧题库与本工具独立；需要迁移进度时，先导入对应题库，再在「数据与设置」导入旧版进度 JSON，或主动点击检测本浏览器旧记录。首次打开不会读取旧记录。原题库与原进度不会被删除。

## 导入格式与校对

可直接使用 [示例资料](./示例资料) 文件夹中的 [DOCX](./示例资料/化学练习.docx)、[TXT](./示例资料/历史练习.txt)、[Markdown](./示例资料/生态学练习.md) 样例。样例不会自动显示在程序里，只有自己选择导入后才会入库。导入 Markdown 样例时，同时选择配套的 [叶片.png](./示例资料/叶片.png)。

推荐题目写法（TXT、Markdown、Word 正文均可使用）：

```text
第一章 基础知识
1. （单选题）Which number is even? 哪个数字是偶数？
A. 3
B. 4
答案：B
解析：4 能被 2 整除。An even number is divisible by two.

2. （多选题）请选择偶数。
A. 2
B. 3
C. 4
答案：AC

3. （判断题）所有偶数都能被 2 整除。
答案：对
```

- 题型可写单选题、多选题、判断题、填空题、简答题、计算题；没有可靠标准答案的题目保留为待补答案，不计入正确率。
- 集中答案可放在同章的「本章答案」或「答案汇总」之后，每行写 `1. B`。题目、答案分文件时，建议一并选择，并写清相同章节名和题号；无法唯一对应的答案在预览中手动关联。
- Markdown 的本地图片请与 MD 一并选择，例如 `![题图](叶片.png)`。程序不会联网下载图片。Word 内嵌的常见图片可以提取，复杂公式只保留可提取的文字，需要校对排版。
- 中文 TXT 出现乱码时，尝试切换为 GB18030 编码重新解析。建议单个文件不超过 20 MB。
- Word 自动列表编号、文本框、复杂表格可能影响识别；最稳妥的方式是在正文显式写题号和答案标记。导入前可编辑题型、题干、选项、标准答案、解析、分类和来源，也可跳过、合并、拆分。

## 操作提示

- 普通练习可以按分类、题型、来源、未做、错题、收藏和关键词筛选；答案按题展开，或显示本页答案。翻页后本页答案自动收起。
- 重刷后可通过「练习轮次」返回原普通练习，原草稿仍在。错题轮结束后可以查看结果，并继续重刷该轮仍答错的题。
- 专注时长为 1–180 分钟；后台和休眠时间仍计入运行中的倒计时，暂停后不扣时。刷新页面不会自动全屏，可再次点击全屏按钮。
- 完整备份是 JSON 数据文件，支持在另一台电脑或另一个浏览器恢复；备份不是需要安装的软件。

## 项目文件与开发

```text
刷题神器.html          可直接双击使用的程序
刷题神器_便携版.zip    程序、README 和导入样例
src/
  shell.html          页面结构
  style.css           页面样式
  parser.js           文档解析与答案匹配
  core.js             题库、判分、错题、计时和存储
  app.js              页面交互
示例资料/             通用导入样例
tests/                核心、解析器和浏览器测试
build.py              合并源文件并生成便携包
测试报告.md           首版验收记录与测试边界
```

修改源码后，在项目目录运行以下命令重新生成 HTML 和便携 ZIP。构建只需 Python 3 标准库，不需要安装第三方依赖。**日常使用 HTML 不需要 Python 或 Node.js。**

```powershell
python build.py
```

开发测试已在 Node.js 24 验证。浏览器测试还需 Windows 上按默认路径安装的 Chrome / Edge：

```powershell
node tests/core.test.js
node tests/fixtures/parser.test.cjs
node tests/browser.test.cjs chrome
node tests/browser.test.cjs edge
node tests/cross-browser.test.cjs
node tests/advanced.test.cjs
```

跨浏览器测试读取 Chrome 测试生成的备份，因此先运行 `browser.test.cjs chrome`。浏览器测试使用独立的临时资料目录，不接触日常浏览器记录；输出保存在已忽略的 `.qa` 目录，不包含在便携发布包中。完整结果见 [测试报告](./测试报告.md)。

## 当前边界

- 支持可提取文字的 DOCX、TXT、Markdown；不支持旧 DOC、PDF、扫描件、OCR 和手写识别。
- 不保证任意排版都能自动识别正确。程序提供预览与校对，不会用 AI 补造标准答案。
- 不提供账号、云同步、联网题库、在线 AI 解析或主观题智能评分。
- 当前以 Windows Chrome / Edge 为验证平台；其他浏览器、操作系统和手机没有同等测试保证。
- HTML 是程序文件，学习数据属于浏览器本地数据。分享 HTML 不会分享你的题库和进度；跨电脑迁移请使用完整备份。
